# ByteBites Reference File

## About This Project
You are building the backend logic for a campus food ordering app called ByteBites
using Python classes and simple algorithms.

## Project Scope
Do not add authentication logic, a database layer, or any features not described 
in the spec.

## Behavioral Instructions

**Scope**
- Only model the four classes in bytebites_spec.md: Customer, FoodItem, Menu, Order.
- Do not add new classes, features, or relationships that the feature request doesn't mention. If you think something is missing, ask me first.
- Do not implement AI recommendations. That is out of scope for now.

**Simplicity**
- Prefer simple Python classes and built-in containers (lists, dicts).
- No inheritance, abstract classes, design patterns, or external libraries unless I ask for them, or I approve a recommendation made by you.
- Keep each class small and focused on one job.

**Code style**
- Use Python 3 with type hints.
- Use clear names (e.g., `purchase_history`, not `ph`).
- Add a short docstring to each class and method.

**Diagrams**
- Use Mermaid class diagram syntax.
- Show only attributes and methods described in the feature request.

**Collaboration**
- Explain your reasoning briefly before giving code.
- When something in the request is ambiguous, list your assumptions
  instead of guessing silently.
